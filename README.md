## 🛠 Features

* **Multi-Slot Processing:** Features independent multi-slot cooking structures backed by decoupled block entity ticker configurations.
* **Energy-Driven Logistics:** Eliminates traditional solid fuel dependencies, operating completely on adjustable Forge Energy (FE) thresholds.
* **Synchronized Render Logic:** Utilizes optimized client/server packet updates for tracking cooking progress thresholds smoothly without visual stutter.
* **Intelligent Network Linking:** Interactive component grids that automatically connect independent auxiliary processing units directly to a main central processing core.

---

## 🚀 Installation & Usage

1. **Verify Your Environment:** Ensure your instance version matches the downloaded target loader binaries (`Forge` or `NeoForge`).
2. **Setup Core Machinery:** Place the central **Flux Oven Core** component next to a stable power cell or distribution pipe.
3. **Expand Assembly:** Link corresponding **Oven Plates** to build your processing network, instantly allowing the system to scale its throughput capacity based on energy input.
